# 픽셀 UI 공방

Godot 4용 픽셀아트 게임 UI 편집기예요. 브라우저에서 바로 열리고, 컴퓨터와 iPad에서 같이 쓸 수 있어요.

- 열기: https://joeseonmi.github.io/pixel-ui-studio/
- 프로젝트는 각 기기의 브라우저에 저장되고, "내 프로젝트 → GitHub 동기화"를 켜면 비공개 Gist로 기기끼리 맞춰져요.
- 이 저장소에는 편집기 페이지만 있어요. 프로젝트 내용은 들어가지 않아요.
